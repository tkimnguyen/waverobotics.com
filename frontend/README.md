# waverobotics.com frontend

Volto 19 frontend of [waverobotics.com](https://waverobotics.com), with
volto-light-theme. The site's own code (logo, header, footer, navigation, theme
customizations) is the add-on in `packages/volto-ploneconf`.

Setup, development, checks and deployment are described in the
[main README](../README.md#frontend).
